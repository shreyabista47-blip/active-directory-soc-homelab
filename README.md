# Active Directory SOC Home Lab

## Project Status

This project is currently under development.

I am building an enterprise-style cybersecurity home lab to simulate a real-world Security Operations Center (SOC). The goal is to practice Windows administration, Active Directory, threat detection, SIEM monitoring, and incident response using open-source and enterprise tools.

Current Progress

- ✅ VirtualBox Environment
- ✅ Windows Server 2025 Domain Controller
- ✅ Windows 11 Client
- ✅ Active Directory Installation
- ✅ Domain Creation
- ✅ Organizational Units
- ✅ User Management
- ✅ Group Policy Configuration
- ✅ Domain Join
